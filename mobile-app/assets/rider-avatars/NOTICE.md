# Rider avatar artwork

These eight 128 × 128 PNGs were generated from DiceBear's Lorelei Neutral style using fixed, non-personal seeds in `shared/riderAvatarCatalog.json`.

- Style: [Lorelei Neutral](https://www.figma.com/community/file/1198749693280469639)
- Artist: [Lisa Wischofsky](https://www.instagram.com/lischi_art/)
- Artwork license: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)
- Generator: `@dicebear/core 10.7.0`, `@dicebear/styles 10.6.0`, `sharp 0.35.5`
- Regenerate locally with `node scripts/generate-rider-avatars.mjs`. Avatar generation and rendering make no third-party image requests.
